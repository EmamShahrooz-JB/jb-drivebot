# اسکوپ‌های Google Drive: کدام را انتخاب کنیم؟

`GOOGLE_SCOPES_MODE` تصمیم امنیتی اصلی این پروژه است.

## مقایسه

| | `file` (پیش‌فرض) | `readonly` | `full` |
|---|---|---|---|
| اسکوپ‌های درخواستی | `drive.file` + `openid` + `userinfo.email` | + `drive.readonly` | + `drive` |
| دیدن فایل‌هایی که ربات ساخته | ✅ | ✅ | ✅ |
| دیدن کل Drive شما (فایل‌های قدیمی) | ❌ | ✅ | ✅ |
| جستجو در کل Drive | ❌ (فقط پوشه ربات) | ✅ | ✅ |
| آمار فضای حساب (`about.get`) | ❌ | ✅ | ✅ |
| تغییر نام/جابه‌جایی فایل‌های ساخته‌شده توسط ربات | ✅ | ✅ | ✅ |
| تغییر/حذف فایل‌هایی که ربات نساخته | ❌ | ❌ | ✅ |
| آپلود فایل جدید | ✅ | ✅ | ✅ |
| سطح ریسک | کمترین | متوسط | بیشترین |

## چطور کار می‌کند

- `drive.file` اجازه می‌دهد اپ فقط به فایل‌هایی دسترسی داشته باشد که **خودش** ساخته یا کاربر با Picker به آن داده است. این «کمترین دسترسی» است و برای یک آپلودر/مدیر پوشه اختصاصی کامل کافی است.
- `drive.readonly` کل درایو را می‌خواند (متادیتا و محتوا) اما هیچ تغییری نمی‌دهد.
- `drive` دسترسی کامل است: می‌تواند فایل‌های موجود شما را هم تغییر دهد یا حذف کند.

Google این‌ها را «restricted scopes» برای `drive` و «sensitive» برای `drive.readonly` طبقه‌بندی می‌کند. برای اپ شخصی بدون انتشار عمومی معمولاً مشکلی پیش نمی‌آید، ولی اگر اپ را منتشر کنید ممکن است Verification بخواهد.

## ربات چطور خودش را تطبیق می‌دهد

`capabilitiesForScopes()` در `src/oauth/scopes.ts` از اسکوپ‌های **واقعاً اعطاشده** استفاده می‌کند (نه از env):

```ts
{ browseWholeDrive, modifyForeignFiles, storageQuota, mode }
```

و UI بر همین اساس رفتار می‌کند:

- `/storage` با `file`: خط «برای مشاهده فضای حساب به دسترسی drive نیاز است» و فقط آمار فایل‌های مدیریت‌شده.
- «My Drive» با `file`: فقط پوشه `JB-DriveBot`.
- حذف فایل غیرقابل‌تغییر: خطای Drive به پیام روشن ترجمه می‌شود (نه stack trace).

## تغییر اسکوپ

1. `.env` را عوض کنید: `GOOGLE_SCOPES_MODE=readonly`
2. `/disconnect` (تا توکن قبلی revoke شود)
3. `/connect` + ابزار محلی

> اسکوپ‌ها در زمان consent تعیین می‌شوند؛ بدون اتصال مجدد اعمال نمی‌شوند. کد اسکوپ‌های ذخیره‌شده را از پاسخ Google می‌خواند، پس اگر Google کمتر از درخواست بدهد، ربات همان را مبنا می‌گیرد.

## توصیه

- کار روزمره (آپلود، پوشه‌بندی، جستجو در پوشه ربات): **`file`**
- می‌خواهید در کل Drive جستجو کنید و آمار فضا ببینید: **`readonly`**
- می‌خواهید فایل‌های قدیمی را هم مرتب/حذف کنید: **`full`** (با آگاهی از ریسک)
